# PyHok Knowledge

Versioned, hypothesis-driven knowledge repository for the PyHok/Sinapse architecture.

## Core Entities

- SignalDefinition
- QuestionEntity
- Relation
- DatasetRelease

## Evolution Model

Kernel evolution:
- Manual
- Compiled
- Released

Policy evolution:
- Controlled
- Versioned
- Invariant-tested

Dataset evolution:
- Automated
- Agent-generated
- Schema-validated
- Conflict-checked
- Released immutably

## Release Principles

1. Semantic Versioning
2. Immutable releases
3. SHA-256 integrity
4. Parent release lineage
5. Engine compatibility declaration
6. Schema versioning
7. Agent proposals are never direct authority
8. Publication only after validation pipeline
